# Анализ строительных компаний

[Блокнот](construction_4120.ipynb) с расчётом EBITA, графиками изменения чистой прибыли и картой компаний с ОКВЭД 41.20.

- [Финансовые данные](results/financials_with_ebita.csv)
- [Рейтинг по выручке за 2025 год](results/revenue_ranking_2025.csv)
- [Карта](results/construction_map.html). Скачайте HTML и откройте его в браузере.

Чтобы запустить блокнот, установите зависимости командой `python -m pip install -r requirements.txt` и выполните все ячейки. [Инструкция по сбору данных ФНС через Selenium](fns_collection/README.md).
